RCAMP / CLI

A serious terminal
companion.

A keyboard-first TUI and command interface for Linux and Windows, powered by the same core as the GUI.

Windows

Run PowerShell as your normal user:

irm https://raw.githubusercontent.com/KiddosTech/RCAMP/main/scripts/install.ps1 | iex

Linux / macOS

Install with curl:

curl -fsSL https://raw.githubusercontent.com/KiddosTech/RCAMP/main/scripts/install.sh | sh

Or wget:

wget -qO- https://raw.githubusercontent.com/KiddosTech/RCAMP/main/scripts/install.sh | sh

FIRST COMMANDS

$ rcamp
RCAMP/CLI  local-first hardware control

$ rcamp devices list
No devices registered. Add a profile to get started.
